# Данные проекта

- Сырые файлы: `data/raw/` (не коммитятся).
- Готовые файлы: `data/processed/` — JSON или GeoJSON, небольшие, лежат в репозитории.
- Скрипт обновления: `python data/scripts/build_data.py`.
- Описание полей каждого набора: `data/README.md`. Если добавляешь набор, обнови описание.

## Источники NASA
Earthdata (`earthaccess`), GIBS/Worldview, FIRMS, POWER, Exoplanet Archive и другие. Брать ресурсы, указанные в описании выбранного челленджа.

## Правила
- Демо не должно зависеть от живых API NASA: всё нужное заранее сохраняется в `data/processed/`.
- Менять формат данных можно только по согласованию с тимлидом.
