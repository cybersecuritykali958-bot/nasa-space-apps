# Data contract

Files live in `android/app/src/main/assets/`; Kotlin models in `data/model/Contract.kt` and `data/model/EngineRules.kt`.
**Change the format only together with the models and only with team lead approval.** Adding entries (new indicators, sources, rules) is fine.

Statuses: `"green" | "yellow" | "red"` (`"unknown"` is code-only).

## indicators.json
```json
{
  "version": 1,
  "indicators": [{
    "id": "heart_rate",               // unique snake_case; key in demo_mission.readings
    "name": "Resting heart rate",
    "unit": "bpm",
    "system": "cardiovascular",       // see body systems below
    "bands": [                        // min inclusive, max exclusive, null = unbounded
      {"status": "red", "max": 40},
      {"status": "green", "min": 50, "max": 100}
    ],
    "baselineDeviationPct": {"yellow": 15, "red": 30},   // optional: % deviation from personal baseline
    "howToMeasure": "...",
    "whySpace": "...",
    "actions": {"green": "...", "yellow": "...", "red": "..."},
    "riskIds": ["cardiovascular"],    // ids from risks.json
    "sources": [{"title": "...", "url": "..."}],
    "verified": false,                // true only after the science review
    "cumulative": false               // true for running totals (dose): no EWMA/CUSUM, trend forecast only
  }]
}
```
The final status is the **worst** of two checks: the `bands` range and the deviation from the personal baseline.

**Body systems:** `cardiovascular`, `metabolic`, `immune`, `behavioral`, `musculoskeletal`, `vision`, `radiation`.

## environments.json
```json
{"version": 1, "environments": [{
  "id": "mars_transit", "name": "Earth-Mars transit",
  "gravityG": 0.0, "radiationMsvPerDay": 1.84, "commDelayMinOneWay": 12.0,
  "sources": [{"title": "...", "url": "..."}]
}]}
```
`commDelayMinOneWay` is the typical one-way delay in minutes (the real range for Mars is ~3–22).

## risks.json
```json
{"version": 1, "risks": [{
  "id": "sans", "name": "...", "hazard": "Altered gravity",
  "system": "vision", "summary": "...", "url": "..."
}]}
```
`hazard` is one of the 5 NASA HRP hazards: Space radiation, Isolation and confinement, Distance from Earth, Altered gravity, Hostile closed environment.

## engine_rules.json
Every tunable number and rule of the engine (`data/model/EngineRules.kt`, details in `docs/BACKEND.md`):
- `earlyWarning`: EWMA / CUSUM / trend (`ewmaLambda`, `ewmaL`, `cusumK`, `cusumH`, `trendWindowDays`, `trendHorizonDays`, `trendMinT`, `baselineWindow`, `minHistory`).
- `confidence`: `staleAfterHours`, `estimatedSources`.
- `triage`: `responseWindowMin` per status, `groundHandlingMin`.
- `patterns[]`: `id`, `name`, `summary`, `all[]`, `any[]`, `minAny`, `riskIds`, `advice`, `sources`, `verified`.
  Condition: `{"indicator": "...", "minStatus" | "statusIn" | "minDeviationPct" | "maxDeviationPct" | "hasAlert"}`; every field that is set must hold.
- `readiness[]`: `id`, `name`, `gates[]` (`indicator`, `cautionAt`, `noGoAt`), `spaceWeatherGate`.
- `schedule`: `intervalDays`, `minutesPerMeasurement`, `attentionIntervalDays`, `redRecheckHours`.
- `gamification`: points, `coreIndicators`, `pointsPerLevel`, `levelTitles`.
- `spaceWeather`: `sepWarningHours`, `cmeWatchHours`, `cmeFastSpeedKms`, `flareWatchHours`, `careerLimitMsv`.
- `input.limits`: `{indicatorId: {min, max}}` plausibility bounds against typos (not medical thresholds). Every indicator needs an entry; `AssetContractTest` checks that all demo values pass.

## donki_cache.json
Real NASA DONKI events for offline use. Generated by `python science/fetch_donki.py`; never edit by hand.
```json
{"version": 1, "fetchedAt": "2026-11-14T10:10:00Z", "source": "NASA DONKI",
 "events": [{"type": "SEP|CME|FLR", "id": "...", "time": "2026-09-05T16:30:00Z",
             "detail": "...", "speedKms": 1200.0, "flareClass": "X1.2", "link": "..."}]}
```

## Room (on-device data)
Table `readings`: `indicatorId`, `value`, `timestampMillis`, `source` (`manual` | `watch` | `camera` | `pvt` | `demo`).
Table `baselines`: `profile` (`DEMO` | `ME`), `indicatorId`, `value`, `source` (`mission` | `manual`).
