# Чек-лист деплоя

- [ ] `web/` развёрнут на Vercel, `api/` на Render или Railway.
- [ ] Переменные окружения заданы на хостинге, `.env` не в репозитории.
- [ ] `NEXT_PUBLIC_API_URL` указывает на боевой API.
- [ ] Данные из `data/processed/` доступны API.
- [ ] Демо-сценарий пройден на боевой версии, на проекторе и с телефона.
- [ ] Записано демо-видео на случай проблем с интернетом.
- [ ] README, ссылки и описание проекта обновлены.
- [ ] Последний коммит помечен тегом `submission`.
