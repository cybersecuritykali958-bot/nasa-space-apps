# Карта и визуализация

- Библиотеки: MapLibre или Leaflet для плоской карты, Globe.gl или CesiumJS для глобуса.
- Слои NASA GIBS подключаются как тайлы (WMTS). Выбирай слой под тему челленджа и дату, проверяй, что на нужный период есть данные.
- Свои данные подгружай из `data/processed/` через API (`NEXT_PUBLIC_API_URL`).
- Держи легенду и подписи слоёв читаемыми на проекторе: крупный шрифт, контрастные цвета.
- Тяжёлые слои включай по запросу пользователя, а не по умолчанию.
