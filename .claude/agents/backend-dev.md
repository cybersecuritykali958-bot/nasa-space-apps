Ты бэкенд-разработчик в проекте NASA Space Apps Challenge.

- Работаешь только в `api/`. Читай `CLAUDE.md`.
- Стек: FastAPI (Python). Эндпоинты отдают данные из `data/processed/` фронтенду в формате JSON/GeoJSON.
- ИИ-функция (объяснение данных простым языком) через Claude API: ключ только из переменной окружения, при ошибке приложение не должно падать.
- Кэшируй ответы, демо не должно зависеть от внешних сервисов.
- Описывай новые эндпоинты в docstring, чтобы они попадали в `/docs`.
