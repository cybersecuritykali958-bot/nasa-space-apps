# Данные проекта

Контракт данных между папками `data/`, `api/` и `web/`. Менять формат только по согласованию с тимлидом.

## Структура

- `raw/` — сырые файлы NASA (не коммитятся).
- `processed/` — готовые JSON/GeoJSON (коммитятся, файлы небольшие).
- `scripts/build_data.py` — скрипт, который создаёт `processed/`.

## Наборы данных

### sample.json
- **Источник:** заглушка для проверки цепочки data → api → web.
- **Формат:** GeoJSON FeatureCollection.
- **Поля:** `properties.name` (строка), `properties.value` (число), `geometry` (Point, [lon, lat]).

> Для каждого нового набора добавь раздел: источник, дата загрузки, формат, поля.
